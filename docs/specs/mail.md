# メール機能仕様（Sa2 Plus）

ステータス: **実装中（MVP）**  
更新: 2026-08-16  
ドメイン: `sa2-plus.com`（ロリポップ・ハイスピード）

関連: `docs/specs/commercial-public-readiness.md`

---

## ゴール

1. 契約ユーザーは **無料で `@sa2-plus.com` を1つ** 申請できる（自動発行はロリポップ API 公開後）。
2. Gmail 等の一般メールを IMAP/SMTP で接続し、アプリ内メーラー（Thunderbird 風・最低限）で送受信できる。
3. 不正利用（スパム・大量作成）を前提にガードする。

---

## ① メールアカウント作成

```
ユーザー申請
  → Sa2 Plus（審査・1枠制限）
  → 【現状】管理者がロリポップ管理画面で手動作成
  → 【将来】ロリポップ公開 API で自動作成
  → ユーザーがアプリ内メーラーに接続
```

### 現状（手動）

- ロリポップ公開 API の「メールアカウントの作成・管理」は **近日公開予定**（[開発者ページ](https://lolipop.jp/rentalserver/developers/)）。
- アプリは申請・承認・「作成済み」記録まで。**サーバ上のメールボックス実体は管理者が手動作成**する。
- UI・管理画面に **「ロリポップ API：近日公開予定。公開後に自動作成へ接続予定」** と明記する。

### 将来（API）

- 運営の PAT で `POST` 相当のメール作成を呼び、ローカルパート＋パスワードを設定。
- 成功後に `mail_accounts` を自動登録し、ユーザーはパスワード再入力なしでメーラー利用（パスワードは暗号化保存）。

---

## ② パスワード管理

| 方針 | 内容 |
|---|---|
| 誰が決めるか | **ユーザー自身**がメールパスワードを決める（管理者は平文を常時閲覧しない） |
| 申請時 | ローカルパートのみ必須。パスワードは「作成完了後、ユーザーがメーラー設定で入力」 |
| 保管 | IMAP/SMTP 用パスワードは `mail_accounts` に **暗号化（Laravel encrypted cast）** |
| 表示 | UI では再表示しない（変更時は新規入力のみ） |
| 将来 API | 作成 API に渡した直後に暗号化保存。管理者ログに平文を残さない |

一時パスワードを管理者から口頭／別チャネルで渡す運用は許容するが、アプリ内に「管理者向けパスワード平文一覧」は作らない。

---

## ③ Webメール

| 選択 | 採用 |
|---|---|
| ロリポップ Webメーラー | 補助のみ（案内リンク可）。主UIにしない |
| **Sa2 Plus アプリ内メーラー** | **採用**（ヘッダー「メール」） |

理由: Gmail 等の複数アカウントを同一UIで扱える。ブランドと権限制御をアプリ側に置く。

---

## ④ SMTP / IMAP（外部クライアント）

| 項目 | 方針 |
|---|---|
| Outlook / スマホ標準メーラー | **利用可**（ロリポップが提供する IMAP/SMTP） |
| 案内 | 接続情報（ホスト・ポート・SSL）をヘルプに記載 |
| アプリ側 | 同じ資格情報でアプリ内メーラーも接続 |

アプリがメールサーバの代わりになるわけではない。実体はロリポップ（または Gmail）側。

## ⑤ 不正利用対策（必須）

自己サービスで無制限に `@sa2-plus.com` を切れる状態にはしない。

| 対策 | MVP |
|---|---|
| 無料枠 | **契約（ユーザー）あたり `@sa2-plus.com` は1つまで** |
| 自動作成 | **無効**（API 近日公開。公開後も即オープンにしない） |
| 承認 | 申請は **管理者承認必須** |
| レート制限 | 申請 POST に throttle（例: 1時間に3回） |
| ローカルパート | 英数字・ハイフン等に制限。予約語（admin, postmaster, abuse 等）禁止 |
| 監査 | 申請・承認・却下・作成済みの日時と操作者を記録 |
| 停止 | 管理者はアドレスを停止扱い（ステータス）にできる |
| 送信 | アプリからの送信もアカウント所有者のみ。将来は日次送信上限を検討 |
| 登録全体 | 招待制と併用（既存の公開ブロッカー対策と整合） |

API 公開後も「承認済み申請のみ API 実行」「1ユーザー1枠」「失敗・乱用時は即停止」を維持する。

## アプリ内メーラー MVP

- 3ペイン: アカウント／フォルダ | 一覧 | 本文
- 機能: 受信一覧、既読表示、本文表示、新規作成・送信、アカウント追加（Gmail / カスタム / `@sa2-plus.com` プリセット）
- Gmail: アプリパスワード前提（OAuth は後続）
- 未実装（後続）: 下書き、検索高度化、添付プレビュー、フィルタ、スレッド、オフライン同期

### 一覧の高速化・保持方針（2026-08-16）

- 一覧キャッシュは30分、開いた本文キャッシュは1時間保持する。
- `mail_message_headers` に **受信一覧のメタデータだけ**（UID・件名・差出人・受信日時・既読）を同期し、画面表示はDBを優先する。
- IMAP同期は15分ごとのcronと、画面の「再読み込み」で実行する。本文・添付はDBに常設保存しない。
- 定期同期の対象は **`@sa2-plus.com` メールボックス優先**。Gmail等の外部アカウントはサイドバー「その他のアカウント」にまとめ、選択時のみ読み込む（`mail:sync-metadata --all` で全件同期可）。
- DBはアカウント／INBOXごとに最新500件までに制限し、メールアカウント・ユーザー削除時は外部キーで削除する。
- Gmail IMAP がホスティング側の通信制限で到達できない場合、DB同期もできない。将来の代替として Gmail API + OAuth を検討する。

## データ

- `mail_accounts` … ユーザー接続設定（IMAP/SMTP・暗号化シークレット）
- `mail_domain_requests` … `@sa2-plus.com` 申請（pending / approved / rejected / provisioned / suspended）

---

## 権限

- メニュー機能 `mail`（ロール既定: SuperAdmin / Admin / Standard / Light）
- 申請の承認・作成済みマークは `admin`（ユーザー管理相当）
