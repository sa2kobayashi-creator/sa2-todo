# 販売検討用：課金が発生しうる要素一覧

ステータス: **記録（販売検討材料）**  
記録日: 2026-08-11

現状はほぼすべて**運営側の外部サービス課金**で、エンドユーザーへの実徴収（Stripe 等）は未実装です。

関連:

- `docs/specs/commercial-storage.md` … ストレージ接続・クォータ・将来の Stripe
- `docs/specs/commercial-public-readiness.md` … 公開・複数利用の実装ギャップ（登録・PII・レート制限など）

## 1. ストレージ・メディア配信（最大のコスト候補）

| 項目 | 用途 | 課金の性質 | 備考 |
|---|---|---|---|
| **Cloudflare R2** | 写真・動画のホット保管 | 保管量・オペレーション | アプリ全体で API キー1セット |
| **Backblaze B2** | コールド／アーカイブ | 保管・転送（egress）・API 呼び出し | 動画再生の署名URL直配信で転送が増えやすい |
| **Cloudinary** | 表示用変換・編集パイプライン | 変換・帯域・保管 | パイプライン設定次第 |

**製品側の無料枠（ユーザーごと）:** 合計 **20GB**（R2+B2 相当）。超過時は見込料金表示のみで、実課金は未実装。超過かつ有料未契約ならアップロード停止（`PHOTO_BLOCK_UPLOADS_OVER_FREE_QUOTA`）。

| **Stability AI** | AI鮮明化（Upscale） | **クレジット従量** | ダッシュボードで残高表示 |

| **SwinIR** | VPS 鮮明化 | 直接API課金なし | GPU VPS 代 |

## 3. LLM・翻訳・検索 API

| 項目 | 用途 | 課金の性質 |
|---|---|---|
| **OpenAI (ChatGPT)** | 入出金音声→構造化など | トークン従量 |
| **Google Gemini** | 同上（切替） | トークン／枠従量 |
| **DeepL** | メモ等の翻訳 | Free 月文字上限／**Pro 月額＋文字従量** |
| **YouTube Data API** | 動画検索 | クォータ超過で課金・制限 |

※ LLM の使用量自動集計はアプリ側では未対応（設定済みかの表示が中心）。

## 販売検討向けの読み方

1. **変動費が大きい順の目安:** 写真動画ストレージ（R2/B2＋転送）→ Cloudinary → Stability/LLM/DeepL → Maps
2. **ユーザー増で効く:** 20GB/人の無料枠設計、動画の転送、AI鮮明化のクレジット
3. **固定寄り:** サーバー、ドメイン、（必要なら）GPU
4. **売り方の分岐:** 運営がクラウドを持ち従量請求する／顧客が自分の R2 等キーを持つ（`commercial-storage.md` の A/B）
