# 従量課金の利用制限（プラン別テンプレート）

ステータス: **実装中（2026-08-27）**  
対象: 運営キーで動く Light / Standard / **特別枠** / テナント契約の原価を、枠で止めて運用可能にする

関連:

- `docs/specs/commercial-storage.md` … ストレージ容量（ユーザーごと。本メモは AI・翻訳の枠と運営画面）
- `docs/specs/commercial-tenants.md` … テナント契約・自前キー
- `docs/specs/commercial-billing-inventory.md` … 外部課金の一覧
- `docs/specs/product-direction.md` … 公開料金・Workers AI

## なぜ必要か

ストレージ以外（LLM、Workers AI、DeepL、Maps、変換、動画転送）は呼び出しのたびに運営の請求が乗る。  
`.env` の**全員共通の日次上限**だけでは、Standard とテナント（最大5名）が運営キーを共有したとき月額を読めない。

## 権限（誰が何を触るか）

| 誰 | 上限の編集 | 見えるもの |
|---|---|---|
| **運営（SuperAdmin）** | **設定 → 制限管理**でプラン別テンプレートと、運営全体の非常停止 | 全プランの枠、見積円、使用量 |
| **テナント代表** | **不可**（運営キーを自分で外せるため）。自前キー運用でも枠の編集は第2段 | 使用量画面で契約プールの残り |
| **Standard / Light** | 不可 | 機能側のエラー（「今月の枠です」）。設定の制限画面は出さない |

例外の「この契約だけ少し上げる」は、テンプレートをいじらず **テナント行の上書き**（未実装。当面はテンプレート変更か SuperAdmin が手で緩める）。

**特別枠**はテンプレートの上書きではなく、運営が**ユーザー管理で付けた個人アカウント**だけに使う列。テナント代表は付けられない。

## 制限の単位

| 対象 | ストレージ | AI・翻訳・生活ガイド |
|---|---|---|
| Light / Standard（個人） | **ユーザーごと**（既存どおり） | **ユーザーごと** 日次＋月次 |
| 特別枠（個人） | **ユーザーごと** | **ユーザーごと** 日次＋月次（制限管理の特別枠列） |
| テナント契約 | **ユーザーごと**（1人あたり GB） | **契約プール**（所属ユーザー合算。5人×個人枠にはしない） |
| 運営 SuperAdmin | 既存クォータ | **上限なし**（生活ガイドと同じ） |

日次はバースト防止。**月次を本命**にする。  
`0` は従来どおりその期間は無制限。

## 特別枠（運営が招待した個人）

自己登録の**招待コード**（知っている人が Light で登録）とは別。  
運営（SuperAdmin）がユーザー管理の「ユーザーを追加」または編集で **特別枠にする** を付けた個人だけ、制限管理の **特別枠** テンプレートを使う。

| 判定 | 使う枠 |
|---|---|
| SuperAdmin | 上限なし（特別枠フラグは無視） |
| テナント所属 | **テナントの契約プール**（特別枠フラグは付けない。付いていても使わない） |
| 特別枠オンの個人 | **特別枠**テンプレート（Light / Standard ロールや有料契約フラグより優先） |
| それ以外 | Light または Standard |

初期値は Light 相当。家族・テスター用に制限管理で厚くも薄くもできる。自己登録では付かない。

## 運営キーと自前キー

- **運営キー**（個人 Standard / Light / 特別枠、およびキー未設定のテナント）… 上記テンプレートを**必ず**適用する。試用30日も含む。
- **テナントが自分のキーを保存して有効**… 原価は契約者側。それでもバグ・ループ用に同じテンプレートを上限として残す。契約者が枠を自分で上げる UI は後回し。
- 誰のキーかを画面で間違えないこと（制限管理の説明文に書く）。

## 80% 警告と 100% 停止

- **100%:** その機能を止める。メッセージは「プランの今月の枠です。変更は運営へ」。自分では解除できない。
- **80%:** 運営の使用量・制限管理に警告を出す。ユーザー向けメールは後回し。
- 停止の解除は、翌月のリセットか、運営がテンプレート／非常停止を変える。

## 運営全体のサーキットブレーカー

ユーザー枠とは別に、運営キー相当の**今月の見積円**が上限を超えたら、SuperAdmin 以外を止める。  
単価は荒い見積（音声1回・ガイド1回・翻訳1000文字）。正確な公式請求ではない。  
`0` でブレーカーオフ。あわせて **全停止フラグ**（障害・請求事故）を置く。

## 画面

- **設定 → 制限管理**（SuperAdmin のみ）。使用量の隣。Light / Standard / 特別枠 / テナントの表＋運営ブレーカー。
- 使用量画面から「制限を編集」で来られる。特別枠ユーザーは「このアカウントの枠」に特別枠と出る。
- **ユーザー管理**（SuperAdmin のみ）で特別枠のオン／オフ。一覧にバッジと**今月の使用量**、詳細に枠ごとの使用量。

## 実装（このリポジトリ）

- テーブル `usage_limit_policies`（`plan` = `light` / `standard` / `special` / `tenant` / `platform`）
- `users.special_quota` … SuperAdmin だけ付けられる
- `UsageLimitPolicyService` … 保存・プラン判定・GB
- `UserUsageLimitService` … 日次に加え月次・テナント合算・ブレーカー
- `BillingEntitlementService` … 保存済みならストレージ GB をテンプレートから

## まだやらない

- Stripe 実課金・超過の販売
- テナント代表が枠を編集する画面
- 契約ごとの上書き行
- ユーザーへの 80% メール

## 運用メモ

招待制のうちはテンプレートを厚くしてもよい。自己登録フルオープンの前に、制限管理の見積円と公式使用量を見てから緩める。  
家族・社内テスターは自己登録コードではなく **特別枠** で招待し、枠だけ独立して調整する。
